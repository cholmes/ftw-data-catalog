# AGENTS.md — Fields of the World — Global Data (1st Edition)

Guidance for AI agents and automated clients working with this Portolan/STAC object.

- This directory is part of the **Fields of the World — Global Data (1st Edition)** catalog
  (`https://data.source.coop/ftw/global-data/`). It is superseded by the
  [2nd Edition](https://data.source.coop/ftw/global-data-2e/catalog.json) (`rel: latest-version`
  on this root catalog); this 1st Edition remains published at its existing URLs.
- Data files (GeoParquet, COG, Zarr, PMTiles) are hosted on Source Cooperative and referenced in place; this repo carries metadata only.
- Prefer the machine-readable `llms.txt` in this directory for query snippets and access patterns, and `README.md` for human documentation.
- Resolve assets and structural links relative to this object; catalogs carry no `self` links.
